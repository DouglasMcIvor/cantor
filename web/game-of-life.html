ℵ Cantor — Game of Life

Conway's Game of Life, compiled from Cantor to WebAssembly, on a 30×30 torus — a glider walking off one edge reappears on the opposite edge. Every frame is one Event through a proof-carrying event loop whose Output is a bitmap (docs/design-decisions.md §6's Nat * Nat * Unsigned32* convention) rather than text — see the text-based demo for the original shape.

The program

Grid = Bool*
Image = Nat * Nat * Unsigned32*

-- Whether (x, y) is alive in `grid`. The board is a torus: `count_neighbors`
-- only ever calls this one step outside [0, width()) / [0, height()), so a
-- single conditional wrap sends an off-the-left edge back to the right edge
-- and vice versa.
cell : Grid * Int * Int -> Bool
cell(grid, x, y) {
    wrapped_x : Int = if x < 0 then x + width() else if x >= width() then x - width() else x
    wrapped_y : Int = if y < 0 then y + height() else if y >= height() then y - height() else y
    idx : Int = wrapped_y * width() + wrapped_x
    (
        if idx < 0 or idx >= len(grid) then
            false
        else
            grid[idx]
    )
}

-- The standard Game of Life rule: a live cell survives with 2 or 3 live
-- neighbors, a dead cell is born with exactly 3.
next_alive : Bool * Nat -> Bool
next_alive(alive, n) = (
    if alive then n == 2 or n == 3 else n == 3
)

main : Char* * Grid -> Image * Grid
main(event, grid) {
    next : Grid = next_generation(grid)
    pixels : Unsigned32* = render(next)
    ((width(), height(), pixels), next)
}

Every function above — including cell's bounds check and the grid-indexing inside it — was verified by cvc5 before this page was ever built: there is no way for this program to index off the end of the grid at runtime.

Built with cantor build --target wasm32. Source on GitHub.
