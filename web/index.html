ℵ Cantor

A compiled, proof-carrying esoteric language. This page runs a real Cantor program — verified by cvc5, compiled through LLVM to WebAssembly. See also Game of Life, an event loop whose Output is a bitmap instead of text, and the Quantum Paper Bag, which solves the Schrödinger equation in fixed-point integers to tunnel its way out of a sealed bag.

main is an event loop: it takes an input line and the current State, and returns a line to print and the next State. Here State is a Nat counting how many lines have been seen, so each reply repeats your text once more than the last. The compiler proved i - 1 never leaves Nat before this page was ever built.
