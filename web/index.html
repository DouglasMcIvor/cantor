ℵ Cantor

A compiled, proof-carrying esoteric language. This page runs a real Cantor program — verified by cvc5, compiled through LLVM to WebAssembly.

The program

main : -> Nat
main() = 1

main : Char* * Nat -> Char* * Nat
main(text, n) {
  mut i : Nat = n
  mut out : Char* = text
  while i > 0 {
    out := out ++ " " ++ text
    i := i - 1
  }
  (out, n + 1)
}

main is an event loop: it takes an input line and the current State, and returns a line to print and the next State. Here State is a Nat counting how many lines have been seen, so each reply repeats your text once more than the last. The compiler proved i - 1 never leaves Nat before this page was ever built.

Built with cantor build --target wasm32. Source on GitHub.
